# Python - File Handling

## Description
This project introduces file input and output operations in Python.

## Learning Objectives
- Open and read files.
- Write text to files.
- Read file contents using `read()`.
- Use the `with` statement to manage files.
- Understand UTF-8 encoding.

## Files
- `read_file.py`: Contains a function that reads a text file and prints its contents to standard output.

## Requirements
- Python 3.8.5
- Pycodestyle 2.7.*
- All Python scripts must start with `#!/usr/bin/env python3`.
