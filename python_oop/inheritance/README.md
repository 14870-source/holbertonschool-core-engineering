# Python - Inheritance and Polymorphism

This project introduces inheritance and polymorphism in Python.

## Topics

* Base classes
* Inheritance
* Parent and child classes
* Method overriding
* Polymorphism
* Class validation
* `isinstance()` and `issubclass()`

## Directory

`python_oop/inheritance`

## Requirements

* Python 3.8.x
* Ubuntu 20.04
* PEP8 / pycodestyle
* All Python files must be executable
* All files must end with a newline
