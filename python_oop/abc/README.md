# Python - Abstract Classes and Interfaces

This project introduces abstract classes, abstract methods, interfaces, duck typing, multiple inheritance, and mixins in Python.

## Topics

* Abstract Base Classes (ABC)
* Abstract methods
* Interfaces
* Duck typing
* Subclassing
* Multiple inheritance
* Mixins

## Task 0

The `animals.py` file defines an abstract `Animal` class with an abstract `sound()` method.

It also defines two concrete subclasses:

* `Dog` — returns `"Bark"`
* `Cat` — returns `"Meow"`
